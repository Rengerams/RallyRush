# Rally Rush 0.3.0 — release notes draft

**Status:** Draft. Do not publish until release validation and Windows install/upgrade checks are complete.

## What’s new

- Practice drills for returning serves and targeting selected court lanes.
- Quick-play presets and clearer match setup.
- Replay pause, resume, and speed selection, plus a post-match coaching note based on match stats.
- A more readable serve follow-through, richer match music, and clearer referee calls.
- More consistent player movement and slide deceleration, with stamina recovery that distinguishes walking from standing still.
- Better screen-reader announcements for score changes and callouts, and reduced-motion support for match callouts.

## Validation status

- Automated tests, lint, production web build, and the deterministic AI playtest matrix pass. See [the quality baseline](quality-baseline-0.3.0.md) for results and remaining checks.
- Windows build reported working by the project owner. Clean install and upgrade testing on Windows 10/11 remain to be recorded.
- Version number, installer download, dependency review, and known-issues list are pending release validation.
